# APP 与后台联调

个人中心的好好绿主题与布局保持不变。以下链路通过真实 Fastify HTTP、后台 SQLite、Flutter 本地 SQLite 和实际客户端服务验证；外部行情供应商使用明确隔离的测试夹具。

| 链路 | 接入行为 |
| --- | --- |
| 配置发布 | `/app/config` 使用既有安装标识参与灰度；校验布尔开关和文档版本；支持回滚、下线和后端地址隔离缓存 |
| 功能开关 | AI 在服务端执行前校验；OCR、语音、自动记账在客户端启动前校验；云备份在客户端和服务端校验 |
| 帮助与运营 | `/app/operations` FAQ 展示在使用手册；Banner、活动以纯文本展示在首页，不能下发可执行内容或任意跳转 |
| 设备状态 | `/app/heartbeat` 登录后及前台维护时上报，按账号间隔一小时；开关改变后主动更新；不采集品牌、型号、金额或支付内容 |
| 会员策略 | 免费和被取消会员均返回功能策略；自动记账启动、CSV 导出、报表分享在实际操作前校验；本地完整备份和恢复继续可用 |
| 工单 | APP 创建工单，后台回复，APP 读取回复；沿用真实消息与工单服务 |
| 云备份 | 后台授予会员后绑定数据、初始化通道、上传真实 SQLite 快照、下载并暂存恢复；后台仅读取备份元数据 |
| 切换账号 | 云操作检查会话是否变化，网络请求绑定开始操作时的会话，避免将旧账号的操作提交给新账号 |
| 多客户端共享 | 修复旧测试对启动日志和随机端口的错误假设；使用隔离测试启动器验证双数据库同步、冲突、撤销权限和数据隔离 |
| 行情契约 | APP 搜索、报价与历史曲线通过真实行情代理接口；A 股、基金字段使用测试夹具，不代表接入正式数据源 |

配置与运营内容缓存按后端地址隔离，30 分钟刷新，7 天过期。成功的空发布覆盖旧缓存；网络失败保留有效缓存，帮助页显示离线提示并可主动重试。配置失败一分钟后可重试。日志上传采样、实验分组及 `ruleVersion` 不会在本批中改变本地设置。

自动记账开关只在开启前校验权限，关闭不受会员限制。前台恢复时若已验证的配置或会员策略禁止自动记账，停止已启用的服务。云自动备份仍需用户选择开启、绑定当前账号并建立首次备份；配置不得替用户开启开关。

## 验证命令

```sh
cd server
npm ci
npm run typecheck
node --import tsx --test test/*.test.ts
cd ..
flutter analyze
flutter test test/app_runtime_repository_test.dart test/membership_execution_guard_test.dart test/help_page_regression_test.dart
flutter test test/shared_backend_integration_test.dart
flutter test --dart-define=ALL_FEATURES_FREE_FOR_TESTING=false test/app_backend_integration_test.dart
```

真实联调已加入 CI，生产权限测试显式关闭免费测试放行，避免调试模式掩盖权限问题。测试启动器仅允许 `NODE_ENV=test`，使用临时数据库、隔离账号及固定测试行情供应商。

## 尚未完成的边界

- 后台现有正则规则与 Android 保守标签规则不兼容，未直接执行远端正则；规则接口现明确返回此限制，仍使用已验证的本地规则。
- A 股与境内公募基金仍需接入覆盖及授权明确的数据源。Twelve Data 适配器与标准行情代理不等于国内基金实时净值服务。
- 云备份仍沿用现有 gzip v2 格式，本批未实现端到端加密 v3 或迁移用户备份。
- 本批未部署生产、未合并 PR，也未操作真实用户账本或后台生产配置。
