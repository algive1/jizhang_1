## 行为与数据

`AutoBookkeepingPage` → 背景、标题、状态卡片、来源、规则、策略、示例、真实近期记录、悬浮检测按钮。`AutoBookkeepingPermissionsPage` 保留原权限设置与运行日志；进入即检测，诊断按钮可重复检测。来源、四条规则及检测按钮均进入该页。通知优先使用原生 AppNotice；无法附着原生窗口时使用应用内悬浮提示。

只有自动记账已启用，且无障碍、悬浮窗、通知渠道、通知读取、所需服务连接和后台运行检查通过时，来源/规则才显示已开启。未知、关闭或异常时显示已关闭，并隐藏来源绿色勾。截图保存与电池优化豁免为可选项；厂商自启动无法直接读取时仍保留设置提示。

保守模式全部待确认；智能模式要求加权置信度≥90%且账本、账户、分类等信息明确；完全自动处理完整有效结果。退款须匹配原流水，内部转账须明确转入账户。账户重复尾号、缺字段、权限异常、策略切换或写入失败保留待确认。默认保守；模式持久化，后台处理读取最新设置。原生识别分数跨队列传递，不为旧数据虚构置信度。

自动和手动确认共用原保存逻辑与稳定交易ID，重复回放只完成队列、不再次扣款；自动推断不会被当成用户修正用于学习。并发到达的账单进入持久化队列，已主动暂存的账单不被自动队列重新处理。
