# 分类顺序、流水分类编辑与目标类型选择验收

日期：2026-10-05。

## 实现与关联入口

- 分类仓库统一展示顺序，支出一级分类以餐饮开始、其他结束，收入的其他收入位于末尾。保留各账本分类模板、自定义分类和中间分类的用户排序，二级分类随所属一级分类排列。记一笔和自动确认的局部倒序逻辑已移除，二级分类也使用公共排序。
- 分类管理限制固定首尾项的移动按钮，避免界面提供无效的排序操作。
- 分类选择引用已核查：记一笔、编辑流水、自动记账确认、分类管理、流水筛选、分类预算、周期账单创建及编辑、账单导入、语音确认、OCR 默认分类、账单收件箱纠正分类。它们读取公共分类仓库；确认表单的网格使用相同的排序。
- 流水菜单统一内置“编辑分类”，覆盖首页近期流水及展开列表、流水列表、搜索、详情操作菜单、账户详情、资产总览流水、消费日历、报销和分期列表及详情。沿用业务规则，为有收支分类的流水提供此操作；跨账本操作仍先切换到流水所属账本。
- 分类编辑复用确认页的 CategoryGrid 和二级分类浮层，支持当前分类回显、已归档原引用、仅保留一级分类、取消及商户记忆。账单收件箱复用这一编辑入口。修复清除二级分类时数据复制逻辑仍保留旧引用的问题。
- 创建目标的 17 个目标类型改为图标卡片网格。普通手机三列，小屏或大字号两列，选中卡片高亮并显示勾选。点选返回创建表单，保留名称、金额等已填内容。
- 目标图标由公共映射提供，创建页、目标列表/进度卡片、详情和首页目标卡片保持一致，并兼容首页已有的旧图标标记。

## 验证

- 20 个相关测试文件中的 121 项用例通过，包含综合回归与目标专项复测。覆盖新旧账本、分类隔离、自定义分类、历史引用、首尾顺序、长按菜单、一级/二级保存、商户记忆、取消、金额与余额、自动确认、预算、周期账单、语音、目标及流水详情。
- 修改范围的 Dart 静态分析无问题；差异空白检查通过。
- 三项 Flutter 视觉测试通过，使用真实中文与 Material 图标字体，检查 393×844 / 1.0 浅色、320×640 / 1.6 浅色、600×960 / 1.6 暗色。预览包括目标类型网格、创建表单、分类编辑及二级浮层。
- 当前没有连接的 Android 设备。上述预览来自 Windows Flutter 测试渲染，尚未进行设备视觉验收或重新构建安装包。
