# 2026-10-10 洞察、投资与数据安全改造

本轮基于 main `892ed3c`，保留好好绿个人中心的页面文件和布局，复用已有洞察引擎、行情代理、云备份与恢复服务。

## 本轮交付

- 洞察页采用本月个人消费、关注分类、结论与依据、处理入口的纵向结构。比较上月同期的同一日历窗口，以人民币净个人消费计算，排除退款、报销、转账、投资转换、未来与已删除记录。无比较基数时不展示虚构百分比；数据加载失败时不生成空数据结论。
- 远程洞察等本地依赖就绪再生成；切换账本/重新分析期间不展示上一请求的服务端结论。洞察详情的证据支持换行。
- 投资新增时保留计价币种和交易所，账户选择按币种过滤，并在账务镜像写入时再次验证币种。行情按标的、类型、币种匹配后写入实际资产缓存键。混合持仓刷新保留手动估值。
- 投资按原币种查看，币种之间不直接相加。缺少报价时显示成本估算并隐藏未知盈亏，显示报价时间和刷新入口。明示行情涨跌与持仓盈亏的含义。修复日快照不可达代码；现有快照仅记人民币，其他币种不绘制混合趋势。
- 服务端新增 Twelve Data 官方搜索、报价、日历史适配，保留现有标准代理。凭据只由服务端读取；包含超时、有限缓存、并发合并、保守的免费请求预算、响应验证与部分成功处理。尚未配置任何真实密钥，未做真实账号行情联调。
- 数据与安全页面复用云备份/恢复流程，增加按账号和数据集独立保存的自动备份开关。默认关闭；首次手动备份后可开启；发生云端版本冲突时暂停。重复生命周期调用不会同时上传。
- 预算页面跟随全局主题、深色模式与语义文字/表面颜色。目标读取失败显示重试。玻璃/实体公共表面补充 Material，支持列表与水波纹正常绘制。
- 通知收件箱、商户规则、经济事件、广告事件采用随机唯一 ID。数据库升至 26，为新库与旧库补齐交易查询索引。后台用户、事件、版本、订单列表重置动作联动筛选字段。

## 验证

- Flutter 3.47.7 / Dart 3.13.5：`flutter analyze --no-pub` 无问题。
- 移动端相关测试四批共 141 项通过：投资计算/持仓/缓存/多币种/窄屏、洞察计算/大字体/深色模式、数据库/迁移、云备份开关/冲突、本地恢复、个人中心与玻璃表面、首页洞察、预算两种主题的正常/深色/大字体/空数据/错误状态等。
- 洞察浅色/深色页面用真实 Flutter 组件和固定审核样本渲染，检查布局。样本不是用户数据或真实行情。
- 服务端：类型检查、88 项测试通过，其中 6 项新增行情适配测试，验证标的与币种、并发合并、异常响应不泄漏凭据、部分报价失败、额度与历史时间窗。
- 后台：lint、类型检查与生产构建通过。浏览器流程未能验证：安装器取得的 Chromium 不完整，另一次官方 Chrome 下载的程序在本环境启动崩溃。未把浏览器启动失败记作业务流程通过。
- Flutter 默认初始化曾被自动审批拦截云实例元数据探测；检查 SDK 源码后使用 `CI=true` 跳过该探测，并用 `FLUTTER_SUPPRESS_ANALYTICS=true` 关闭遥测，完成移动端验证。验证环境的 tar 解压使用 `--no-same-owner`，未改变产品配置。
- CI 增加新增回归用例；本地没有 Android/iOS 原生发布构建结果。

## 上线边界与后续工作

- Twelve Data 接入需要服务端 `MARKET_DATA_PROVIDER=twelvedata` 与 `TWELVE_DATA_API_KEY`。股票、ETF、加密币对覆盖由账号套餐与交易所权限决定，不能宣称覆盖全部 A 股、场外基金或债券。公开 APP 展示需确认业务/交易所许可。多服务进程上线前需把额度控制移到共享存储。
- 外币历史趋势需要单独的币种快照迁移；已有币种或市场不明的资产不自动改写。
- 本轮不等于全部后台页面与应用联动已验收：配置下发、原生自动记账规则包消费、完整设备上报、会员能力入口、FAQ/Banner 消费及备份过程遥测仍需单独联调。

具体数据源配置与覆盖说明见 `server/README.md`。
