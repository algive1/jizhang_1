# 木木夜间模式实施与验收

2026-10-04。已按用户确认，把所有主题的夜间配色与材质统一到木木方案：黑底色雾、深色主卡、低透明度玻璃面板和主题色按钮。四个内置主题均已采集原生画面；远程主题也复用同一套夜间规则。静态检查、85 项测试及正式入口 Android ARM64 release 构建通过。

[四主题预览](qa/2026-10-04_木木夜间-预览.png) · [分析页、主题预览和放大字体](qa/2026-10-04_木木夜间-补充验收.png) · [手机安装包](../build/app/outputs/flutter-apk/app-release.apk)

本次依据[木木夜间分析报告](../../fanbianyi/报告/2026-10-03_逆向-木木夜间背景-report.md)及已有 Blutter 输出核对材质参数。没有采集木木原机画面，不能据此声称逐像素复刻；验收截图来自自有 App 的隔离原生入口，数据库为内存演示数据。日间规则保留，夜间继续保留各页面的功能和布局。

## 夜间参数

| 部件 | 本次实现 |
| --- | --- |
| 页面 | `#000000`，按原始主题色派生三团 HSL 色雾，强度固定为参考默认值 50；移除旧夜间照片/渐变覆盖 |
| 主卡片 | `#111111`、圆角 16、无默认阴影；原有 frosted 主卡在夜间也使用此规则 |
| 二级卡片 | 白色 alpha `.12` |
| 局部玻璃面板 | 白色 alpha `.10`，白色边缘 `.24`；高对比度模式使用实色底 |
| 导航 | `#111111 × alpha .50`、模糊 `5/5`；静止选中胶囊白色 `.10`、无模糊/折射 |
| 确认按钮 | 主题色底、可读前景、最小高度 48、圆角 16；禁用态为中性深灰 |
| 记一笔入口 | 白色 `.26`、模糊 `2.5/2.5`，降低夜间光学高光；入口位置、点击和长按行为保留 |
| 普通弹窗/菜单/底部弹窗 | 实色 `#111111` |

色雾按下方、右侧、左上顺序绘制，修正原实现反转 y 坐标的问题。左上为 `(-.85,-.85)/1.18`，右侧为 `(1.05,-.05)/1.10`，下方为 `(-.3,1.15)/1.05`，中心 alpha 分别为 `.2944/.1728/.1152`；HSL 限制与原报告一致。低饱和度主题另走中性色分支。

背景始终使用原始主题色，文字与按钮的强调色单独提亮，避免紫色、黑色及高饱和蓝色远程主题产生低对比度。按钮前景依据实际颜色亮度选择黑/白；此处属于可读性适配。主卡与玻璃面板分开处理，避免所有内容卡都被套上白色玻璃滤镜。

## 验证

- 8 个测试主题：4 个内置主题，以及远程紫色、灰色、黑色和高饱和蓝色。验证主卡实际填色/圆角、玻璃输入、按钮启用/禁用点击、按钮与导航文字对比度不低于 4.5:1、中性色雾及正确的色雾方向。
- 79 项主题、导航、记账、卡片、资料页及布局测试通过；另 6 项路由背景隔离测试通过，总计 85 项。测试文件涵盖 `night_theme_test`、`app_scaffold_navigation_test`、`app_liquid_glass_surface_test`、`liquid_glass_profile_test`、`quick_add_redesign_test`、`secondary_page_layout_test`、`home_asset_card_test`、`profile_reference_test`、`route_background_isolation_test`。
- 修正现有测试对旧缓存键、懒加载滚动项和旧帮助弹窗的假设，继续验证当前“使用手册”入口。
- 原生验收：Pixel 10a API 37.2，1080×2424；4 主题 × 首页/我的/记一笔共 12 张，另含分析页、主题外观、140% 字体和日间对照。截图不含测试调试面板。原始 PNG 在 `.agent/night-mode-20261003/native-final/`。
- 最终涉及文件静态检查无问题；正式 `lib/main.dart` 入口的 ARM64 release APK 构建成功，约 75.7 MB。现有插件/font 打包提示不影响此次构建；尚未在物理手机或 iOS 真机安装验收。
