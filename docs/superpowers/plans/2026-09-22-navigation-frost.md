# 导航栏雾面调整实施计划

用户已确认采用上一轮建议并开始开发。

目标：导航覆盖区保留背景色块，压住背景文字，保证导航可读性。

范围：调整 `lib/core/widgets/app_bottom_navigation.dart` 的底板材质；四个主页面共用。运行验证发现独立导航的批次合成路径丢失底板，因此同步在 vendored `liquid_glass_tab_bar.dart` 的 `withImpeller` 构建分支传入 `batch: false`。保留圆角、几何位置、选中胶囊、中央加号、路由与页面留白。不增加底部全宽遮罩，不修改共用玻璃渲染器。

- [x] 检查背景模糊参数从导航组件到玻璃渲染层的传递：已有 sigma 16，Impeller 批处理采用 blur + shader 合成，非批处理先模糊再折射。
- [x] 先将 `glassTint` 调为 `Color(0xA6FFFFFF)`（约 65% 白色）定位遮挡能力，再按用户要求依次调整为 `Color(0x40FFFFFF)`（约 25%）和 `Color(0x2EFFFFFF)`（约 18%），保留 sigma 16。
- [x] 在同一 debug 会话热重载对照 `batch:true` / `batch:false`：前者底板消失、后者恢复背景模糊与白色底板，保留后者作为局部修复。
- [x] 运行现有导航、胶囊布局、快捷记账按钮测试和相关静态分析；24 项测试通过、两个修改源码文件静态分析通过。渲染问题以 Impeller GLES 的实际 A/B 截图验证，不用重复参数断言代替渲染验收。
- [x] 构建 Android Release 包并覆盖安装模拟器，确认最终包首页底板正确；debug 下检查四个页签、加号交互和“我的”末项留白。
- [x] 记录验证结果、截图、影响与设备验证局限：`docs/development/2026-09-22-navigation-frost.md`。

验收：导航覆盖区背景正文不可辨认，图标与标签清楚；选中胶囊可辨；加号可用；列表末项可滚出导航。若只调底色后仍透字，先用运行画面验证实际模糊路径再进一步修改。
