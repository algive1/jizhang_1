# “我的”与设置整合设计稿（待确认）

日期：2026-10-06。适用主题：好好绿、液态玻璃云雾蓝。

本稿是界面与功能入口方案，尚未修改 Flutter 业务代码。范围限定为两套“我的”、设置及它们直接进入的管理页面。账号、会员、自动记账、备份等沿用现有业务能力；新增的是统一的入口组织和必要的状态呈现。

## 一、建议选第三版：账号整合页

三版使用相同的功能目录，仅布局不同：

| 方案 | 首屏重点 | 适用情况 |
| --- | --- | --- |
| 状态工作台 | 自动记账与云备份状态 | 经常检查授权、自动记账和备份的用户 |
| 轻量常用页 | 六项常用工具 | 希望尽快进入工具、减少信息干扰的用户 |
| 账号整合页（建议） | 账号会员整合，下面是常用工具和管理入口 | 商业应用的日常使用与账号管理并重 |

对比页：http://127.0.0.1:8318/ 。三版绿色效果图用于比较结构；两个主题应使用同一结构，各自保留原有颜色、背景和材质。图中的账号、统计和状态均为示例。

### 推荐页面结构

1. 顶部：标题“我的”、消息入口、设置按钮。
2. 账号区域：头像、昵称、账号中心；会员等级/有效期与会员中心整合在同一区域；显示当前账本，可切换。
3. 当前账本概览：记账天数、连续天数、账单照片。照片可进入照片列表。
4. 常用功能：默认六项“我的账本、账户资产、自动记账、账单导入、预算管理、分类管理”；右侧“全部功能”。
5. 管理与服务：备份与数据、安全与隐私、帮助与反馈。
6. 底部导航沿用现有首页、流水、记账、洞察、我的。

会员区域按真实状态显示“基础版”“会员有效至…”“会员已到期”，进入会员中心后查看权益与购买记录。未登录显示“本地使用”和登录入口；云功能在操作处说明需要登录。会员状态不使用示例等级或虚构积分。

概览全部以当前账本为范围，切换账本后同步更新。真实空数据显示 0，加载与失败使用对应状态；不能把加载失败显示成“从未记账”。两个主题复用同一份统计与跳转逻辑。

常用功能保留已有用户选择和排序；新默认项只用于首次使用。外观设置不再占默认常用位，但用户已主动收藏的设置入口可以保留。“全部功能”页提供“编辑常用功能”，不把长按作为唯一编辑方式。

## 二、“全部功能”的统一目录

| 分类 | 功能 |
| --- | --- |
| 账本与资产 | 我的账本、共享账本与成员、账户资产 |
| 记账工具 | 自动记账、账单导入、小票识别、周期账单、账单照片 |
| 规划与管理 | 预算管理、目标管理、分类管理、信用分期、财税账单 |
| 数据与应用 | 备份与数据、安全与隐私、外观与显示、通知与提醒 |

“我的账本”可选择、创建和管理账本；共享成员与角色由共享账本页面承担。登录账号与资金账户应在名称、图标和帮助文案中明确区分。

“预算与目标”拆成预算管理与目标管理，两主题点同一项进入同一页面。分期、财税归入工具目录，不再放在设置里。照片入口从绿色页面的私有弹层提取为共享入口。支付通知授权/检测归入自动记账，系统通知和提醒归入通知设置。

已有设置快捷方式、服务页和业务路由需要保留兼容入口，不能因为整理目录造成旧入口失效。

## 三、共用设置页

设置由底部弹出菜单改为独立、可滚动的二级页面。三组八个入口，两个主题完全一致：

| 分组 | 入口 | 内容 |
| --- | --- | --- |
| 账号与数据 | 账号管理 | 登录信息、昵称、密码与找回、登录设备、退出登录、注销 |
| 账号与数据 | 备份与数据 | 云备份、本地备份、恢复、账单导入、数据导出 |
| 账号与数据 | 自动记账 | 模式、授权状态、自动记账记录、待确认账单 |
| 账号与数据 | 安全与隐私 | 应用锁、权限管理、隐私偏好 |
| 应用偏好 | 外观与显示 | 两主题、深浅模式、金额显示 |
| 应用偏好 | 通知与提醒 | 系统通知状态、记账及其他已实现提醒 |
| 帮助与关于 | 帮助与反馈 | 使用说明、提交反馈、我的工单 |
| 帮助与关于 | 关于与协议 | 版本、隐私政策、用户协议、会员协议 |

“我的”和设置中的同名管理入口进入同一页面，避免分别维护两份菜单与业务规则。设置不再重复陈列信用分期、财税、小票识别等工具。

安全与隐私需要新建真正的管理入口；现有 `/profile/privacy` 是隐私政策正文，必须保持其协议语义，不能改成权限管理页。权限应显示当前状态、用途与系统设置入口；Android/iOS 分别展示平台支持的项目，避免显示无法操作的权限开关。

## 四、备份与数据的整理

统一数据页使用以下层级，不再把导出、应用锁和开发说明混在一起：

| 区域 | 用户需要看到和操作的内容 |
| --- | --- |
| 云备份 | 登录状态、最近成功备份、当前操作进度、手动备份、查看/恢复备份、失败与重试 |
| 本地备份 | 创建完整备份、备份文件位置/分享、选取备份文件、密码与恢复 |
| 账单导入 | 选择来源、选择目标账本、预览及重复处理、导入结果 |
| 数据导出 | 明确当前账本和导出范围、格式与附件是否包含、成功后分享文件 |

云备份沿用现有快照能力和自动备份策略，文案使用“云备份”。不将快照上传和恢复宣传为实时多端同步或自动合并。当前没有对应控制能力的功能不绘制假开关。

本地完整备份与 CSV 导出分别说明用途：前者用于完整恢复，后者用于查看或迁移账单。CSV 当前只导出选定账本时必须明确显示该账本，不能写“全部账本”。

恢复前展示来源、时间、数据范围以及覆盖影响；确认后操作并显示结果。完整恢复与账单追加导入应采用不同措辞。备份与导出分别显示完成状态，不共用“CSV 已导出”的提示。

## 五、说明内容如何清理

| 内容 | 处理 |
| --- | --- |
| 开发实现、数据库结构、技术调试、接口已经接通等说明 | 从用户界面移除，必要内容放入开发文档 |
| 面向研发的隐私白皮书、内部安全方案 | 移出功能入口；用户所需内容改为具体的权限用途和数据处理说明 |
| 隐私政策、用户协议、会员协议 | 保留在关于与协议；必要的授权/购买场景仍可访问 |
| 应用锁、备份恢复、权限拒绝等操作说明 | 保留，改为结果、限制和操作方法 |
| “我的积分”未开放占位、未经定义的 Lv 等级 | 移除；记账统计继续显示真实数据 |
| 无有效操作的推荐 APP | 移除整个推荐模块 |
| 会员示例评价、未实现能力承诺 | 不出现在新“我的”；其直接跳转页面的相关文案一并核对 |
| 开发调试入口 | 仅开发环境可见，正式界面不出现 |

不是批量删除所有含“隐私”“安全”的内容；处理依据是其是否帮助用户作出实际操作与数据选择。

## 七、确认后应一起补齐的基本体验

- 两个主题账号、会员、照片、设置与同名快捷功能的行为一致。
- 会员有效期、过期和本地使用状态真实可见；去掉未开放占位和样例评价。
- 统计与照片遵循同一当前账本范围，空数据、加载和失败可区分。
- 自动记账显示真实模式及缺失授权；通知权限和通知读取授权区分。
- 备份具有独立进度、最近成功时间、失败提示与重试；恢复前说明覆盖范围。
- 导入明确目标账本和重复处理；导出明确账本、数据范围与附件。
- “安全与隐私”进入管理页，隐私政策仍是可访问的协议正文。
- 保留旧用户收藏和现有路由，字体放大及窄屏可滚动，不遮挡底部导航。

这些是本次直接关联体验的验收条件；后端会员计费、实时同步、业务权限制度的扩展不自动纳入界面整理。
