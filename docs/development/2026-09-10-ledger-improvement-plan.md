本文件把本轮确认的改进计划落入项目文档，按“界面与本地体验 → 账务模型与备份 → 云同步与家庭共享”分阶段执行。每个切片必须先有可复现的测试或真实验收证据，再进入下一切片；未实际联调的外部服务不标记为生产可用。

- [x] 底部数量文案区分“共 N 个账本”和“查看全部账本（N）”。
- [x] 拆分书架背景与独立书本素材，彻底消除空层板上的背景伪账本。
- [x] 将全部账本管理改为可搜索、可滚动、带同步状态的新视图。
- [x] 将新建账本的用途、名称和封面预览合并为一个底部表单。
- [x] 最近交易改为当前账本最近 10 条、按本地日期分组并使用数据库限量查询。
- [x] 交易详情统一入口，补齐附件缩略图、预览、系统打开和缺失文件状态。
