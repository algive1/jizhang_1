# 趋势线统一优化（2026-09-12）

## 目标

统一优化项目中所有数值趋势线，避免曲线在突变数据附近过冲，并保证曲线、数据点、面积填充和拖动选中位置使用同一套坐标。

## 覆盖范围

- 资产总览的资产变化卡片和资产变化详情弹窗。
- 首页的支出趋势。
- 收支分析页的每日收入支出趋势。

目标进度线、资产分布环形图和装饰性绘制不是数值趋势，不使用该算法。

## 修改方案

- 新增 `buildMonotoneSmoothLinePath`，使用 monotone cubic + Hyman filtering。
- 统一返回折线路径和采样点坐标，让 marker、选中点和面积填充不再各自计算位置。
- 收支趋势图的收入、支出两条线均使用统一路径；拖动仍按图表横坐标映射到最近数据点。
- 资产趋势对单点数据增加安全定位，避免极端数据量导致除零。

## 验证结果

- `flutter analyze`：通过。
- 趋势路径、左右拖动选择、资产详情交互测试：通过。
- `flutter test --no-pub`：通过，259 项。
- `flutter build apk --debug`：通过，已安装到 Android emulator `145a0a68`。
- 模拟器实际检查首页支出趋势和收支分析趋势，曲线、采样点、选中点和面积填充对齐。

## 后续约束

新增趋势图优先复用 `buildMonotoneSmoothLinePath`。如果需要自定义曲线，必须同时复用它返回的 `coordinates` 绘制数据点和选中点，避免线与点再次错位。
