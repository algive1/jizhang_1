# 2026-09-18 记一笔导航遮盖与备注布局修复

## 问题与根因

- 首页或流水页长按流水后进入“编辑流水”，底部导航会覆盖“记一笔”的键盘区域。
- `ShellRoute` 的页面上下文默认使用嵌套导航器；由该上下文打开的模态弹层位于 `AppScaffold` 的全局底部导航之下。
- 备注输入框继承了应用全局的表单主题（52dp 最小高度和描边），即使局部指定了 `border: InputBorder.none`，各状态边框仍会从主题回退，造成计算区域卡片被撑高且样式不一致。

## 修复

- 新增 `showQuickAddSheet` 统一入口，使用根导航器展示记一笔弹层。
- 首页、全局快捷入口、流水编辑/复制、详情编辑、助手编辑/快速记账和资产页转账均接入统一入口。
- 备注框固定为单行 40dp，启用紧凑/折叠布局，并显式关闭普通、聚焦、禁用和错误状态的所有边框，避免继承全局表单样式。

## 回归验证

- 首页长按流水后编辑：记一笔弹层命中层位于底部导航之上。
- 流水页长按流水后编辑：同样不会显示或接收底部导航事件。
- 备注框高度、计算卡片相对位置、聚焦和外部点击失焦均由 widget test 覆盖。

## 后续维护

新增记一笔入口时必须调用 `showQuickAddSheet`，不要直接调用 `showModalBottomSheet` 创建 `QuickAddSheet`；否则在 ShellRoute 页面中可能重新出现导航层级问题。
