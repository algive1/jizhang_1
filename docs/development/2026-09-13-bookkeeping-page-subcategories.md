# 记一笔页面与分类子分类扩展（2026-09-13）

## 完成内容

- 记一笔页继续复用现有 `account`、`ledger/book`、`category`、`transaction` 模型和 `QuickBookkeepingService` 保存链路。
- 金额输入按原型显示：左侧保留用户公式（如 `100*2`），右侧显示 `= ¥200.00`；公式写入流水 `metadata.formula`，编辑流水时可以恢复。
- 默认账户沿用微信，账本沿用当前账本；时间 chip 统一命名为“时间”，支持今天、昨天、自定义日期和具体时间。
- 顶部“编辑”进入当前账本的分类管理页，避免切换账本后误改其他账本分类。
- 企业账本动态显示发票、客户、项目、供应商字段，数据写入流水 metadata；个人和家庭账本不显示这些字段。
- AI/语音确认卡拆成独立 `AIConfirmCard`，支持编辑时间和二级分类；保存时写入父分类和 `subcategoryId`。
- 页面组件拆分为金额视图、分类网格、二级分类栏、数字键盘、时间选择器、企业字段和 AI 确认卡。

## 二级分类种子

默认子分类通过现有 Drift 分类表写入，不使用页面硬编码状态。种子 ID 按账本、一级分类和子分类 key 生成，重复启动不会重复插入；同名的用户自定义子分类优先保留。

- 个人账本：餐饮、交通、购物、娱乐、居家、缴费、医疗、教育、旅行、人情、宠物、数码、汽车及主要收入分类。
- 家庭账本：家庭采购、家庭购物、子女教育和家庭收入，并复用通用交通、居住、医疗等子分类。
- 企业账本：商务餐饮、差旅交通、采购、招待、场地、办公缴费、福利、培训、商务旅行、礼赠、营销、软件设备、车辆运营及收入分类。

一级分类被用户归档时不会恢复默认子分类；分类管理仍可继续新增、编辑、排序和隐藏子分类。
