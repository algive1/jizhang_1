# 首页与记一笔 UI 规范（2026-09-09）

## 2026-09-09 实施口径

首页使用暖米白背景、实色卡片、橄榄绿重点色、清晰细边框和深色文字。顶部固定为头像/问候/账本入口/搜索；点击账本名或箭头从顶部安全区向下展开书架抽屉。书架抽屉有顶部把手、悬浮阴影和木质层板，每本书使用独立书脊、封面内框、高光和投影；书本按常规手机每排三本，窄屏或大字号两本。封面显示名称、类型、本地或共享状态，当前账本同时显示边框和勾选。

首页卡片保持紧凑：月账单目标高度不超过 112dp，今日安心可花不超过 120dp，目标卡不超过 160dp（大字号允许自然增高）。月账单、今日额度、目标是三个独立区域，不能用大面积渐变或低对比文字把信息融在一起。无预算显示“未设置”并提供设置入口，无目标显示紧凑创建入口，读取失败显示重试而不是零金额。

月账单的年份和月份分别可点按选择，支持前后月份、跨年、闰年二月和回到本月；未来月份不可选。选择的月份只影响顶部汇总和其流水入口，下方今日预算、趋势和当前月记录继续使用当前月份。切换账本时先清空旧金额，加载完成后再显示新账本数据。

账本文案按类型变化：个人“今日安心可花”、家庭“家庭今日可花”、企业“今日支出额度”；企业月收入减支出称“收支结余”。共享账本入口显示成员、待同步数量和同步状态。

## 设计方向

首页采用项目暖米白底色、实色白/浅橄榄卡片、橄榄绿重点色、清晰细边框和深色文字。主任务顺序固定为：看清本月 → 判断今天可花多少 → 解释支出变化 → 查看最近记录。

视觉基调复用 `AppColors` 的深色文字、暖米白背景和橄榄绿重点色；快速记账仍可复用 `FinanceUi`，首页不修改共享组件的渐变契约。预算接近上限或超支继续使用既有 warning 语义。

## 首页布局

```text
头像 / 问候语 / 搜索

轻量月度汇总：收入 · 支出 · 月度结余

月账单卡：收入 · 支出 · 收支结余 · 年/月选择
今日安心可花卡：额度 · 本期预算 · 剩余天数
目标卡：当前 / 目标金额 · 当前圆环 · 下一站 · 终点

值得关注（有真实洞察时显示，可关闭）
支出趋势（周 / 月 / 年，点按或拖动查看）
分类支出（最多四项，点击查看该分类流水）
净资产入口
最近记录
```

顶部汇总的“月度结余”严格表示本月收入减本月支出，不代表账户余额或净资产。首页不再展示完整的重复“本月支出”大卡，也不重复渲染完整目标卡。

三个卡片各自只有清晰的触控入口：安心可花进入预算管理，月账单进入所选月份流水，目标进入目标详情。没有预算时显示“未设置”和设置入口，不把 0 解释成只能花 0 元；没有目标时显示紧凑创建入口。

## 金额口径

第一阶段的实际计算是：

```text
本期可用支出 = 月度预算 - 已发生支出 - 用户明确开启的目标预留
今日安心可花 = max(0, 本期可用支出) / 本月剩余天数
```

目标预留默认为 0。它必须在目标详情的“每月目标预留”入口中由用户明确开启，保存后才进入预算计算；它只影响展示和预算口径，不扣款、不移动账户资金。未来计划支出、固定账单和周期支出仍未接入，首页计算依据会明确说明这一点。

首页使用目标页排序后的第一个进行中目标。目标排序写入本地数据库，排序或目标进度更新不会覆盖预留设置。

## 支出趋势

趋势来自 `StatisticalAnalysisService.cashflowTrend` 的真实人民币支出：

- 周：近 7 天按日。
- 月：当前月截至今天按日。
- 年：当前年份按月聚合。

图表支持点按和水平拖动；选中点显示日期和金额，辅助功能支持前后点切换。无数据时保留坐标和“记下一笔支出，在这里了解变化”的提示，不伪造曲线。未来记录、删除记录、转账和其他币种不计入支出趋势。

## “值得关注”

洞察使用一条轻量薄荷色 Banner，不使用通知红点。整条进入分析页，关闭按钮保存“洞察指纹 + 当前账期”的关闭状态；关闭不会删除分析数据。没有真实洞察时不占位。

## 记一笔

记一笔采用原型的单页纵向布局：顶部滑动胶囊（支出 / 收入 / 转账）、大金额、五列彩色分类图标、账户／日期／备注分组、语音入口和底部渐变“保存记账”按钮。

类型切换与首页趋势共用连续滑动胶囊组件，选中背景使用 280ms ease-out 动画；支持水平拖动切换，`prefers-reduced-motion`/系统关闭动画时立即切换。大金额点击后展开数字键盘，保存按钮固定在底部，键盘和大字体不会覆盖保存路径。

分类图标只影响表现，不改变现有分类 ID、保存逻辑或转账逻辑。分类没有可用数据时显示明确的分类管理提示。

## 可访问性与响应式约束

- 触控区域有语义 label；预算、计算依据、目标、趋势图分别可定位。
- 金额使用 `FittedBox`、`Flexible` 或 `Wrap`，避免七位数金额挤压标题。
- 320dp 宽度和 1.6 倍文字下，首页、组合卡、趋势和记一笔不产生布局异常。
- 动画不作为唯一状态反馈；颜色变化伴随文字和语义状态。

## 后续扩展边界

计划支出、固定账单、周／年度计划分配、目标预留建议值和云端同步不在本轮的实现范围内。后续新增时必须先扩展数据口径和计算依据，再扩展首页主视觉，不能静默改变“今日安心可花”的含义。
