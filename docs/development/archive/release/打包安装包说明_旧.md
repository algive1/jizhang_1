# jizhang_app — Android 安装包打包说明

项目：`jizhang_app`（Flutter，iOS + Android）
版本：见 `pubspec.yaml` 的 `version:`（当前 `1.0.0+1`）
包名：`com.algive.jizhang_app`

## 一键打包（推荐）

在 **macOS 终端**（Terminal）中执行：

```bash
cd /Users/algive/jizhang_01
bash build_apk_release.sh
```

脚本会自动执行 `flutter pub get` → `flutter build apk --release`，
并把产物复制到：

```
dist/jizhang_app-1.0.0+1-release.apk
```

## 手动命令（等价步骤）

```bash
cd /Users/algive/jizhang_01
flutter pub get
flutter build apk --release
```

产物默认在：`build/app/outputs/flutter-apk/app-release.apk`

## 安装到手机

- 用数据线连接安卓手机（开启 USB 调试），执行：

  ```bash
  adb install -r "dist/jizhang_app-1.0.0+1-release.apk"
  ```

- 或直接把 APK 发送到手机，点击安装（需允许"安装未知来源应用"）。

## 签名说明（重要）

- 目前项目**没有** `android/key.properties` 正式签名文件，
  `android/app/build.gradle.kts` 会让 release 自动退回 **debug 签名**。
- debug 签名的 APK **可以安装自用 / 测试**，但**不能上架**应用商店；
  如需正式发布，请准备签名 keystore，在 `android/` 下创建 `key.properties`：
  ```properties
  storePassword=***
  keyPassword=***
  keyAlias=***
  storeFile=***（相对于 android/ 的路径或绝对路径）
  ```

## 常见问题

| 现象 | 处理 |
| --- | --- |
| `flutter: command not found` | 安装 Flutter SDK，并把 `flutter/bin` 加入 PATH；`flutter doctor` 自检 |
| 构建提示 Gradle/JDK 问题 | 执行 `flutter doctor -v`，确认 JDK 17 与 Android SDK 已就绪 |
| 手机安装提示"签名冲突/已存在" | 卸载旧版本后重装，或用 `adb install -r` 覆盖安装（同签名） |
